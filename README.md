# Online Examination System: Use Case Execution & Navigation Guide

This guide provides the necessary instructions to set up, run, and verify the **Attempt Exam (UC-01)** use case. The system uses a Boundary-Control-Entity (BCE) architecture and is managed via Maven.

---

##  1. Prerequisites
Ensure your environment meets the following requirements:
*   **Java:** OpenJDK 17 or higher (Verified on OpenJDK 25).
*   **Build Tool:** Apache Maven 3.9.15+.
*   **Terminal:** Zsh or Bash (macOS/Linux) or Command Prompt/PowerShell (Windows).

---
